# TestPilot
智测领航 TestPilot：面向基础开发者的智能软件测试平台，2026秋软件工程实践团队项目。

## 目录

- `frontend/` — Vue 3 + TypeScript + Element Plus 前端。
  - 环境、执行与结果页（陈睿涛）：见 [`frontend/README.md`](frontend/README.md)。
  - 项目、需求与用例页（林彦羽，待合并）。
- `backend/` — FastAPI + SQLite 后端（待合并）。
- `docs/api-alpha.md` — 六人共同接口约定（曾炜毅维护，待提交）。
- `demo_service/` — 本地演示服务（郭泽强，`feature/agent-demo` 分支）。

## 前端快速启动

```bash
cd frontend
npm install
npm run dev   # http://127.0.0.1:5173（默认内置 Mock，可独立演示）
```
